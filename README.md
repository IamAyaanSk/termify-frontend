# Termify Playground
#### The Client Component for Termify

------------

The frontend playground for **Termify**
### Sneak Peek
Termify Playground is the actual frontend component that consist the actual Code Editor, Terminal, File trees which provide a seamless experience to userrs allowing them to execute and 
practice coding without the need of setting an environment.
Currently, Typescript, Git, Javascript and Python are supported.

------------

### Features
- An Xterm based terminal which simulates the terminal running on Termify container enabling user to interact in real time.
- A file tree which displays all the created files and folders according to nesting level.  
- Create and manage files and folders directly from terminal.
- Develop and execute commands directly from your web.

------------

### Tech
- React
- Typescript
- Xterm
- Vite
- Socket.io
- Vercel


------------

### Setting up locally

  1. Clone this repo  
   ```git clone https://github.com/IamAyaanSk/termify-frontend.git```

  2. Install dependencies  
   ```pnpm install```

  3. Run the development server   
   ```pnpm dev```

  4. Set env variables ( refer .env.example )
 
  5. Building   
  ```pnpm build```

  6. Starting the server   
     ```pnpm start```
